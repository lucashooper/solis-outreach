# Outreach channels

## Automated (Solis)

| Channel | How |
|---------|-----|
| **Email** | Resend — Groq personalised hook + collab template (`src/pipeline/outreach.ts`) |
| **Discord** | Webhook alerts + rich embeds for best creators after discovery |

## Not automated

| Channel | Why |
|---------|-----|
| **TikTok DMs** | No official outreach/DM API suitable for cold collab pitches |
| **Instagram DMs** | No official Meta messaging API for cold creator outreach in this product |

Manual DMs remain an operator workflow outside Solis. Discovery still enriches TikTok/Instagram **profiles** via Apify; contact for automation is email scraped/extracted from bios.
